# ResNet50 最小基线模型说明

## 定位

该模型用于验证“实体分组数据 → ResNet50 训练 → 风险阈值 → ONNX Runtime 推理”的完整技术链路。当前只有 24 个独立实体，因此结果不能解释为现场选矿准确率。

## 数据与划分

- 矿石：106 张、12 个实体。
- 废石：38 张、12 个实体。
- 图片：256×256 RGB 热成像伪彩色图。
- 分组规则：文件名前缀为实体编号，类别前缀用于避免 `ore_001` 与 `waste_001` 冲突。
- 第 0 折：训练 14 个实体/87 张图，验证 4 个实体/22 张图，测试 6 个实体/35 张图。
- 同一实体的不同视角不会跨训练、验证和测试集。

## 模型

- ImageNet 预训练 ResNet50。
- 当前小样本阶段冻结卷积骨干，提取 2048 维特征，只训练一个线性废石分类头。
- 训练时按类别和实体均衡加权，防止视角较多的实体支配损失。
- 仅使用翻转、小角度仿射和平移等几何增强，不改变热成像色相。
- 输出为 `p_waste = sigmoid(waste_logit)`。
- 单帧废石阈值：`0.2878920585`。
- 阈值在验证图片上按“目标矿误抛率为 0 时尽量提高废石召回率”选择。

## 第 0 折结果

| 评估单位 | 指标 | ResNet50 | 热强度规则 |
|---|---|---:|---:|
| 单张图片 | 准确率 | 91.43% | 94.29% |
| 单张图片 | 平衡准确率 | 91.00% | 93.00% |
| 单张图片 | 废石召回率 | 90.00% | 90.00% |
| 单张图片 | 目标矿误抛率 | 8.00% | 4.00% |
| 实体多视角平均 | 准确率 | 100%（6/6） | 100%（6/6） |

ResNet50 当前没有超过简单热强度规则，说明现有数据主要由整体亮度信号驱动。需要增加独立矿石、不同批次和不同工况后，再判断深度特征是否提供额外价值。

单帧错误集中在两个实体：`ore_005` 的两个视角被误抛，`waste_004` 的一个视角被保守判为目标矿。多视角平均后这两个实体均被正确分类。

## ONNX 部署

导出产物位于 `artifacts/resnet50_baseline_fold0/`：

- `model.onnx`：计算图。
- `model.onnx.data`：外部权重，部署时必须与 ONNX 文件放在同一目录。
- `model.metadata.json`：输入尺寸、归一化、阈值和标签定义。
- `report.json`：训练与评估详情。
- `test_predictions.csv`：测试图片预测记录。

PyTorch 与 ONNX Runtime 的随机输入最大绝对误差为 `7.15e-7`，低于 `1e-4` 验收容限。ONNX Runtime CPU 推理已经用真实矿石和废石图片跑通。

## 下一步

1. 使用相同采集参数增加独立矿石数量，而不是只增加同一矿石的视角。
2. 清除热像仪界面标记并保存原始温度矩阵。
3. 对四个实体分组折分别训练 ResNet50，报告均值和波动。
4. 数据达到数百至数千个独立实体后，再逐步解冻 `layer4` 和全网络微调。
5. 现场单帧分选继续采用保守阈值；如果硬件允许连续拍摄多个视角，可使用实体级概率平均降低偶然误判。
